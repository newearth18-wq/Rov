# Rift Arena

เกม MOBA 2D ต้นฉบับสำหรับเบราว์เซอร์ เล่นกับบอตหรือสร้างห้องเล่นกับเพื่อน ตัวละคร ภาพ และชื่อทั้งหมดสร้างสำหรับเกมนี้

## เปิดเล่นในเครื่อง

ใช้ Node.js **22.13 ขึ้นไป** (แนะนำ Node 24):

```sh
npm start
```

เข้า http://127.0.0.1:4173 ไม่ต้องติดตั้งแพ็กเกจสำหรับเปิดเล่นหรือทดสอบ ฐานข้อมูลห้องในเครื่องอยู่ใน `.sites-runtime/rooms.sqlite` และไม่ถูกส่งขึ้น Git

## สิ่งที่เล่นได้

- สนาม 5v5 สามเลน ครีป ป้อม ฐาน และมอนสเตอร์ป่า
- ฮีโร่ 6 แบบ: อัศวินรอยแยก, จอมเวทดารา, นักล่าแสง, ผู้พิทักษ์ศิลา, เงาคมมีด และผู้เยียวยาแสง
- เลือกออฟเลน เลนกลาง แครี่ ป่า หรือโรม พร้อมรูนและพลังแฝง
- สกิลเฉพาะตัว: ฟันวงกว้าง ยิงเวท โจมตีระยะไกล สตัน โล่ กระโดดลอบสังหาร และฮีลทีม
- ไอเทม 6 ชนิด ซื้อระหว่างแมตช์และขายคืน 60% พร้อมเงินจริงในแมตช์และค่าสถานะที่เปลี่ยนตามไอเทม
- บอตเลือกเดินตามตำแหน่ง ฟาร์มป่า ซื้อไอเทม ใช้สกิล และถอยเมื่อเลือดน้อย
- เงิน เลเวล ช่วยฆ่า แบ่งรางวัลครีป กลับฐาน เกิดใหม่ และผลการแข่งขัน
- ภาพสนามป่า ภาพฮีโร่ เอฟเฟกต์การโจมตี โล่และสตัน พร้อมเสียงเปิด/ปิดได้
- เมาส์ คีย์บอร์ด จอยสัมผัส และแผนที่ย่อบนมือถือ

## เล่นกับเพื่อน

1. ทุกคนเปิดเว็บเกมเดียวกัน เลือก **เล่นกับเพื่อน** แล้วเลือกฮีโร่ ทีม ตำแหน่ง รูน และพลังแฝง
2. คนหนึ่งกด **สร้างห้อง** ส่งรหัส 6 ตัวและลิงก์เกมให้เพื่อน
3. เพื่อนกรอกรหัสแล้วกด **เข้าห้อง** ตำแหน่งหนึ่งมีผู้เล่นได้หนึ่งคนต่อทีม รวมสูงสุด 10 คน
4. ถ้าเปลี่ยนตัวเลือกหลังเข้าห้อง ให้กด **ยืนยันฮีโร่และตำแหน่ง** ก่อนเจ้าของห้องกดเริ่มแมตช์
5. บอตเติมตำแหน่งว่าง และแทนผู้เล่นที่ออกจากห้อง

เจ้าของห้องรันการจำลองแมตช์และต้องเปิดแท็บเกมไว้ การพักหรือซ่อนแท็บของเจ้าของทำให้ทุกคนพักด้วย ผู้ร่วมเล่นพักเฉพาะหน้าจอตัวเองได้ เมื่อเจ้าของออกหรือรีโหลดห้องจะปิด เริ่มรอบใหม่ด้วยห้องใหม่ เข้าเพิ่มได้เฉพาะก่อนเริ่มเกม ห้องไม่มีการใช้งานหมดอายุหลัง 1 ชั่วโมง

ออนไลน์เป็นต้นแบบที่ส่งคำสั่งและสถานะผ่าน HTTP กับฐานข้อมูล (ประมาณทุก 250 มิลลิวินาทีขณะเล่น) ความลื่นขึ้นอยู่กับเน็ตและเครื่องเจ้าของ ยังไม่มีเซิร์ฟเวอร์จำลองกลาง ระบบป้องกันโกง หรือการย้ายเจ้าของห้องอัตโนมัติ การเข้าถึงเว็บขึ้นกับสิทธิ์แชร์ของเว็บที่เผยแพร่ด้วย รหัสห้องใช้เข้าร่วมเกมและไม่เปลี่ยนสิทธิ์เข้าถึงเว็บ

## วิธีเล่น

| การกระทำ | คีย์ / วิธี |
|---|---|
| เดิน | WASD, ลูกศร, คลิกสนาม หรือจอยสัมผัส |
| โจมตีศัตรูใกล้สุดในระยะ | Space, คลิกขวา หรือปุ่มโจมตี |
| สกิลเฉพาะตัว | Q |
| พุ่งไปทางเมาส์ / ทิศเดิน | Shift |
| อัลติเมต | E |
| กลับฐาน | B — ยืนนิ่ง 4 วินาที |
| พัก / เล่นต่อ | Escape |
| ขายไอเทม | กดไอเทมในช่อง |

ดันครีปให้รับการโจมตีของป้อม ทำลายป้อมทั้งสองในเลนใดเลนหนึ่งเพื่อเปิดเกราะฐาน แล้วทำลายฐานฝ่ายตรงข้าม

## ตรวจสอบและ build

```sh
npm test
npm run build
```

ชุดทดสอบโหลดโค้ดเกมจริงและจำลองแมตช์จนจบ ตรวจฮีโร่ รูน ไอเทม สกิล โล่ สตัน ฮีล คูลดาวน์ การพัก เกิดใหม่ และผลชนะ–แพ้ ชุดออนไลน์ใช้ Worker และ SQLite จริงสองผู้เล่น ตรวจสิทธิ์เจ้าของ การไม่เปิดเผย token ตำแหน่งชนกัน คำสั่งซ้ำ ลำดับแพ็กเก็ต เดิน ซื้อไอเทม สถานะร่วม และการออกจากห้อง ตรวจภาพและคำสั่งผู้เล่นร่วมผ่านเบราว์เซอร์เพิ่มเติม

Build สร้าง Cloudflare Worker ที่ `dist/server/index.js` และรวมไฟล์หน้าเว็บกับภาพไว้ใน Worker ใช้ D1 binding `DB` สำหรับห้องออนไลน์ โครงสร้างฐานข้อมูลอยู่ใน `db/schema.ts` migrations สร้างด้วย Drizzle หลังแก้ schema:

```sh
pnpm install
pnpm db:generate
```

## โครงสร้าง

- `dist/index.html`, `style.css` — ล็อบบี้ ห้องออนไลน์ HUD ร้านค้า และมือถือ
- `dist/game.js` — การเล่น บอต การวาด Canvas และ WebMCP แบบตรวจการรองรับ
- `dist/network.js` — ห้อง คำสั่งผู้เล่น และการแสดงสถานะที่เจ้าของส่งมา
- `dist/assets/` — ภาพฮีโร่และแผนที่ต้นฉบับ สร้างด้วย imagegen
- `server/worker.mjs` — API ห้องและไฟล์หน้าเว็บบน Sites
- `server.cjs`, `server/local-db.cjs` — เซิร์ฟเวอร์ในเครื่องและตัวเชื่อม SQLite
- `scripts/build.mjs` — build สำหรับ Worker
- `db/schema.ts`, `drizzle/` — schema และ migrations
- `.openai/hosting.json` — เว็บไซต์เดิมและ binding สำหรับเผยแพร่
