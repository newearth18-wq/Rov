# Rift Arena

เกม MOBA 2D ต้นฉบับสำหรับเบราว์เซอร์ ใช้แนวคิดฮีโร่ เลน ครีป ป้อม ป่า รูน และไอเทม เป็นเกมเล่นคนเดียวกับบอต ไม่ได้ใช้ตัวละคร ภาพ หรือเสียงจาก RoV

## เปิดเล่น

เปิด `dist/index.html` ด้วยเบราว์เซอร์ได้ทันที หรือใช้ Node.js 18 ขึ้นไป:

```sh
npm start
```

เข้า http://127.0.0.1:4173 ไม่ต้องติดตั้งแพ็กเกจ

## สิ่งที่เล่นได้

- 5v5: คุณและบอต 4 ตัว ปะทะบอต 5 ตัว บนแผนที่ 3 เลน
- ฮีโร่ 3 แบบ: อัศวินรอยแยก จอมเวทดารา นักล่าแสง
- เลือกรูนเพิ่มพลังโจมตี พลังชีวิต หรือความเร็ว และความยาก 3 ระดับ
- สกิลโจมตีวงกว้าง พุ่ง และอัลติเมตเฉพาะฮีโร่ พร้อมคูลดาวน์
- ครีปเกิดเป็นระลอก ป้อมเลือกโจมตีครีปก่อนฮีโร่เมื่ออยู่ในระยะ
- มอนสเตอร์ป่าให้เงิน ประสบการณ์ และบัฟโจมตี
- เงิน เลเวล การซื้อไอเทม 6 ชนิด และช่องไอเทมสูงสุด 6 ช่อง
- กลับฐาน ฟื้นฟูพลังชีวิต ตายแล้วเกิดใหม่ สถิติ K/D/A และผลการแข่งขัน
- เมาส์ คีย์บอร์ด และจอยสัมผัส เสียงเอฟเฟกต์เปิด/ปิดได้
- พักเกม และพักอัตโนมัติเมื่อสลับแท็บ

## วิธีเล่น

| การกระทำ | คีย์ / วิธี |
|---|---|
| เดิน | WASD, ปุ่มลูกศร, คลิกสนาม หรือจอยสัมผัส |
| โจมตีศัตรูใกล้สุดในระยะ | Space, คลิกขวา หรือปุ่มโจมตี |
| สกิลวงกว้าง | Q |
| พุ่งไปทางเมาส์ / ทิศเดิน | Shift |
| อัลติเมต | E |
| กลับฐาน | B — ยืนนิ่ง 4 วินาที |
| พัก / เล่นต่อ | Escape |

ดันครีปให้รับการโจมตีของป้อม ทำลายป้อมทั้งสองในเลนใดเลนหนึ่งเพื่อเปิดเกราะฐาน แล้วทำลายฐานฝ่ายตรงข้าม ไอเทมซื้อได้ทุกที่ในแมตช์ รูนและไอเทมมีผลต่อค่าสถานะจริง

## ตรวจสอบ

```sh
npm test
```

ชุดทดสอบโหลดโค้ดเกมจริงใน DOM จำลอง ตรวจการเริ่มเกม รูน การซื้อไอเทม เงินไม่พอ สกิล คูลดาวน์ การพัก การเกิดใหม่ เกราะฐาน และผลชนะ–แพ้ รวมถึงจำลองแมตช์ยาวเพื่อตรวจค่าที่ผิดปกติ การตรวจภาพและปุ่มทำเพิ่มเติมในเบราว์เซอร์

## ขอบเขตเวอร์ชันนี้

นี่คือต้นแบบสนามรบแบบ 2D แสดงตัวละครด้วยสัญลักษณ์ ยังไม่มีออนไลน์หลายผู้เล่น บัญชีผู้ใช้ แรงก์จริง กิลด์ สกิน หรือระบบซื้อด้วยเงินจริง ข้อมูลแมตช์อยู่ในหน่วยความจำและเริ่มใหม่เมื่อรีโหลด ไม่มีกำแพงที่ขวางการเดินหรือระบบซ่อนตัวในพุ่ม

ฟอนต์โหลดจาก Google Fonts หากไม่มีอินเทอร์เน็ตจะใช้ฟอนต์ของเครื่อง ระบบเกมไม่ต้องพึ่ง API หรือฐานข้อมูล

## โครงสร้าง

- `dist/index.html` — หน้าเลือกฮีโร่ HUD ร้านค้า และหน้าผลการแข่งขัน
- `dist/style.css` — รูปแบบและหน้าจอมือถือ
- `dist/game.js` — เกม ลอจิกบอต การวาด Canvas และ WebMCP ที่ตรวจการรองรับก่อนใช้
- `server.cjs` — เซิร์ฟเวอร์ไฟล์สำหรับเปิดเล่นในเครื่อง
- `.openai/hosting.json` — การเผยแพร่ผ่าน Sites
